## Решения владельца — одна строка на решение

- **D01 / 2026-10-18 / BASE §44, Block 7:** **Free AI plan отсутствует**, стартовые AI-кредиты/бесплатные AI-allowances не начисляются; коммерческая точка входа в AI — **Trial $0.99**, НЕ активировать и не обещать неутверждённые условия.
- **D02 / 2026-10-18 / BASE §28, Block 7 Everyday Tools:**

**Уточнение к D02 (2026-10-18):** Жёсткий дневной лимит допустим для не-AI облачной услуги либо услуги с нулевым риском денежных списаний; он **НЕ отменяет Issue #182**: если вызов — платный облачный AI-provider, без приобретённых AI credits даже при лимите вызывать его нельзя. Это не бесплатный AI-план.
 инструменты Everyday Tools бесплатны **каждый день**, если полностью локальные или не вызывают платный облачный AI; облачный платный сервис требует локальной альтернативы **либо жёсткого дневного лимита на пользователя с гарантированной блокировкой денежных перерасходов**, без свободных неоплаченных AI-диспетчеризаций.
- **D03 / 2026-10-18 / Block 6 Voice:** бесплатный AI-Voice, бесплатные голосовые сообщения, AI first-win и стартовые бесплатные AI-запросы отменены; Voice/облачная STT/TTS/AI доступны только **оплатившему** пользователю согласно Block 7; локальные безопасные utilities остаются Everyday Tools, не новым Voice-планом.
- **D04 / 2026-10-18 / Issue #182, BASE §§13–18, Blocks 1/2/6/7:** AI-провайдер вызывается **только на подтверждённо купленные кредиты**; оплаченный и подтверждённый Stripe **Trial $0.99 является покупкой**, но до отдельного решения владельца entitlement/кредиты/срок/повторные регистрации/возвраты неизвестны, checkout **не включать**.
- **D05 / 2026-10-18 / BASE §53, §21, Block 2:** этап 1 User Agent = заранее определённые **workflow-сценарии** с явным подтверждением; полный многошаговый **автономный оркестратор только после LIVE_VERIFIED коммерческой цепочки BASE §51**, без второй agent-базы/роутера.
- **D06 / 2026-10-18 / BASE §53, Block 5:** этап 1 Product Watcher **лайт**: uptime сайта, ошибки Stripe, аномалии трат и email владельцу при проблеме, owner-only и без автоприменения критических изменений; новости моделей, auto-remediation, сложная аналитика и остальное — этап 2 после §51/отдельного допуска.
- **D07 / 2026-10-18 / BASE §§24–25, Block 4, Block 8:** единственный канон **Block 4 — My Workspace / History / My Creations**, поверх уже существующих таблиц generation jobs; остальные тексты только ссылаются, не создают второй project/history store, сервис или PR.
- **D08 / 2026-10-18 / BASE §§22–23, Blocks 3/4:** единственный канон **Block 3 — Inspiration + шаблоны как данные** (одна существующая таблица/каталог); Studio в Block 4 только показывает/использует шаблоны, не дублирует их хранение/админку/PR.
- **D09 / 2026-10-18 / BASE §§13–18, §§43–44, Blocks 1/2/6:** единый коммерческий канон **Block 7 — цены, купленные кредиты, Stripe, Trial $0.99, расчёт экономии/лимитов**; остальные места содержат ссылки, а не независимые условия и таблицы.
- **D10 / 2026-10-18 / Block 3 Inspiration:** примеры допускаются только **собственные, действительно бесплатно сгенерированные без риска списания либо явно помеченные заглушки**; платная AI-генерация примеров без отдельного разрешения запрещена; не выдавать placeholder за настоящий результат.
- **D11 / 2026-10-18 / правила §7:** всем агентам разрешены **проверенно бесплатные** unit, mock, CI, Stripe test-mode и реальные вызовы по тарифам без рисков списания; перед каждым настоящим AI-вызовом записать в GitHub CHECKPOINT сервис/модель, доказанную бесплатность, лимит/остаток, жёсткий отказ вместо платного перерасхода, дату/источник; если нельзя доказать — НЕ запускать, `BLOCKED`. **Бюджет платных тестов = 0** для всех.
- **D12 / 2026-10-18 / правила §13, §11, §22:** `CI_BLOCKED` — допустимый отдельный статус; финал кодового агента **READY_TO_MERGE** с открытым PR и зелёными обязательными бесплатными тестами; `DONE` только после реального полного **LIVE_VERIFIED**, не после коммита/CI/DEV-merger.
- **D13 / 2026-10-18 / правила §9/§21:** закреплены ответственные: Audio = B (provider) + C (local Tools); AI Agents = C (UI) + Jules2 (изолированный Block2 workflow) + B/D (paid path); Inspiration = C (канон Block3, A/B media только по handoff); History = A (Block4 UX) + B/D (server privacy peer review); SEO = A (редактура) + C (своя навигация) + D (release/indexation), координатор #5 устраняет конфликты. Это разделение работ, **не разрешение менять чужие файлы**.
- **D14 / 2026-10-18 / правила Jules:** **Jules — один исполнитель/очередь Google с максимум тремя одновременно подтверждёнными активными задачами**; bot ACK обязателен, отсутствие ACK или task-creation failure = `QUEUED_NOT_RUNNING`; исключить дубли PR и вмешательство в A–D.
- **D15 / 2026-10-18 / все документы:** исходные формулировки сохраняются для аудита, в местах изменений ставится датированная пометка; правила 1–4 неизменны; изменяется только документация (не код, production, Stripe, суммы/цены, API-расходы или миграции).

## Вопросы владельцу — НЕ предполагать ответы и НЕ запускать Trial

1. **Длительность** Trial $0.99: срок в днях/часах, момент старта и момент окончания?
2. **Кредиты**: сколько именно *купленных AI-кредитов* и какие модели/возможности доступны после подтверждённой оплаты?
3. **Продление**: разовая покупка или возможна подписка, кто и как подтверждает будущее продление?
4. **Возвраты**: политика возврата $0.99, отказов/отмен и возврата кредитов, включая уже потраченные?
5. **Защита от повторных регистраций**: одно Trial на кого (аккаунт, Stripe customer, платёжный метод и др.), какие меры законны/допустимы?
6. **Облачные Everyday Tools**: согласовать перечень конкретных инструментов, которым допустим облачный вызов с жёстким дневным per-user лимитом, и покрытие себестоимости без риска списаний владельца.
7. **Конфликт исторического сравнения Lumina:** старые тексты с `3 дня / 299 кредитов / no renewal` — **не условия Deepsyq**; следует ли удалить их из будущей публичной презентации после отдельного утверждения условий?
