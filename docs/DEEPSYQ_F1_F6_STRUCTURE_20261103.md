# DEEPSYQ — Каноническая структура функционала F1–F6 (2026-11-03)

**Прямое распоряжение владельца от 03.11.2026 (Решение D22).**  
Действует для всех координаторов (P), разработчиков, моделей (ChatGPT, Antigravity, Jules) и агентов.

---

## 1. Суть реорганизации

В ходе развития платформы голосовой ассистент и агент задач были реализованы в едином интерфейсе — **Jarvis (Jarvix)**, а модуль виртуальных питомцев (F8) был полностью закрыт и удален из кодовой базы. 

Чтобы исключить любую путаницу в нумерации и разработке, владелец утвердил объединение и оптимизацию структуры проекта до **ровно 6 пунктов (от F1 до F6)**:

1. **F2 и F6 объединены в один пункт — `F2: Jarvis`**:
   - Прежний **F6 (Voice Agent / Голосовой агент)** и прежний **F2 (User Agent / «Сделай за меня»)** теперь образуют единый модуль **F2 — Jarvis (Voice & User AI Assistant)**.
   - Больше нет отдельного пункта F6 для голоса: весь голосовой интерфейс, микрофон, синтез баритоном, barge-in (перебивание голосом) и интеллектуальные сценарии выполнения задач живут внутри **F2**.
2. **Перенос биллинга на освободившееся место F6**:
   - Прежний пункт **F7 (Pricing / Credits / Stripe)** перемещён на номер **F6**.
3. **Удаление F8**:
   - Прежний **F8 (Virtual Pet Companion / Питомцы)** закрыт, заморожен и полностью удален из проекта.

## 3. Правило для участников разработки

- **Запрещено** использовать старую нумерацию (F1–F8) в новых отчётах, коммитах, PR и документации.
- **Запрещено** дробить Jarvis обратно на отдельные независимые модули F2 и F6.
- При коммуникации в чатах и координации задач использовать только актуальные обозначения **F1 — Compare**, **F2 — Jarvis**, **F3 — Inspiration**, **F4 — Workspace**, **F5 — Watcher**, **F6 — Pricing/Stripe**.
