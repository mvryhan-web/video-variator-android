# CEDAR COURT 14A — экранная читаемость R3

Владелец отклонил читаемость автоматически открываемого PDF R2: виден дом, надписи слишком мелкие. Причина проверена: ArchD2592×1728pt с текстом8–12pt при fit-to-window даёт очень мелкие подписи. Прежняя проверка текстовых границ/резкости не доказывала экранную читаемость. Обязательно проверять пользовательское окно/превью и физический масштаб текста.

Создана ОТДЕЛЬНАЯ экранная версия A4landscape21страница: русский текст, основные подписи/таблицы13–18pt, заголовки22pt, footer11pt. План и мебель заново выведены из реального R2DXF с крупными названиями/ID. Таблицы оборудования, комнат, проемов и координат разнесены. Каждый из4фасадов/2разрезов отдельно из реального векторного PDF, старый крошечный текст удалён только из временной копии представления; исходная модель/CAD/техническийPDF сохранены. Крупные описания не перекрывают рисунки. Добавлены площади, геометрические толщины/высоты и наружные размерные цепочки. Схемы без масштаба, не предназначены для измерения линейкой.

Все21страница просмотрены при ширине1200px, проверены границы текста, минимальный размер шрифта11pt (footer), основной13–18. Никакого заявления о строительной проверке: это исправление читаемости, не завершение инженерных разделов. Не называть SCREEN R3 технической заменой размерным листам ArchD. Ничего не публиковалось.

PDF для владельца: https://drive.google.com/file/d/1WBzhyRYaAvTjD38yuRUMNxm4Nn456JY6/view?usp=drivesdk . Текущая геометрияV08 и статусы R2 остаются. При показе в чате использовать крупные экранные страницы, не прежние миниатюры всего большого листа. До любой публикации требуется проверка владельцем, кроме того сохраняются ранее записанные технические и платформенные блокеры.
