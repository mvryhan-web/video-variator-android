# RyhanGoods — обязательные правила цифровых товаров

Утверждено владельцем 26 октября 2026. Применять при каждой следующей работе с товарами RyhanGoods. Это отдельная деятельность от Deepsyq.

1. Работать по одному товару: исследование спроса, согласованный состав, создание, проверка, упаковка, доставка, объявление. Не считать попытку загрузки завершением.
2. Исследовать реальные аналоги: фиксировать URL, дату, цену, отзывы именно товара и свежесть отзывов. Продажи магазина, отзывы и избранное не выдавать за продажи товара. Не обещать высокие продажи, прибыль или место в топе без доказательств.
3. Сначала сообщать владельцу название продукта, аудиторию, точный состав и порядок создания. Изображения создавать и показывать в чате; каждый элемент отдельным файлом. Не заменять 30 файлов одним коллажем. Проверять каждый элемент на ошибки, повторы, края, прозрачность и соответствие стилю.
4. Печатные растровые иллюстрации: целевой размер 4500x4500 px или обоснованный размер для конкретного формата, 300 DPI. Проверять фактические пиксели и размер печати. Не называть увеличение разрешения дополнительной детализацией. Векторный PDF проверять по размеру страницы и качеству растровых вставок. Для A4/US Letter создавать и проверять обе версии отдельно.
5. Чистые файлы покупателя без рекламных водяных знаков. Отдельные превью Etsy с небольшими полупрозрачными RyhanGoods, расположенными так, чтобы затруднить копирование; не обещать абсолютную защиту.
6. Для Etsy создавать отдельную главную обложку, обзор всего комплекта, крупные примеры, применение, размеры/форматы и инструкцию скачивания. Мокапы должны правдиво показывать фактический товар. Высокое разрешение, читаемость на мобильном экране, отсутствие ложных заявлений.
7. Уникальный понятный английский заголовок без лишних повторов и набивки ключевыми словами; проверить актуальные требования Etsy. Описание: польза, точный состав, форматы/размеры/язык, совместимость, ограничения, скачивание, лицензия, отсутствие физической доставки. Не обещать то, чего нет. Указывать помощь ИИ правдиво в настройках и описании, когда требуется.
8. Ровно 13 релевантных Etsy тегов, каждый не более 20 символов включая пробелы. Это теги, не хэштеги с #. Проверять длину программно.
9. ZIP: только окончательные файлы покупателя плюс инструкция и лицензия; без исходников, секретов, внутренних метаданных и рекламных превью. Проверить распаковку, количество, названия и открытие всех файлов.
10. Google Drive: использовать подтвержденный аккаунт MV Anton (идентификатор проверять через профиль подключенного Drive). Создать отдельную папку с названием товара. Загружать готовый ZIP. Для ZIP — доступ anyone with link / reader, без права редактирования и без рассылки уведомлений. Не открывать доступ к посторонним файлам. Учесть, что ссылку можно переслать. Проверять доступ и скачивание.
11. Использовать предоставленный владельцем шаблон RyhanGoodsinstr(5).png как основу PDF-инструкции. Оригинал сохранять неизменным. Для каждого товара делать отдельную версию с точной кликабельной ссылкой на его ZIP. Проверять визуальный PDF и реальную ссылку, не только текст ссылки на картинке.
12. Etsy: загружать PDF со ссылкой как цифровой файл покупателя и отдельные рекламные изображения; выбирать instant digital download. Проверять категорию, автора, AI disclosure, цену, количество, 13 тегов, файлы и отсутствие ошибочно подставленного производственного партнера/физической доставки.
13. СОХРАНЯТЬ ТОЛЬКО ЧЕРНОВИК. Ничего не публиковать без отдельного указания владельца после проверки. Подтвердить сохранение повторным чтением статуса и реальной ссылкой на объявление.
14. Правила и шаблон хранить в GitHub для повторного применения. Не утверждать сохранение шаблона, загрузку на Drive или создание товара до фактического завершения и проверки. Правила не означают, что все описанные шаги уже выполнены.
