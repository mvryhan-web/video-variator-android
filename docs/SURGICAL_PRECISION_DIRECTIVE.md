# ПРЯМОЕ РАСПОРЯЖЕНИЕ ВЛАДЕЛЬЦА: ТОЧЕЧНЫЕ ИЗМЕНЕНИЯ БЕЗ ЛИШНИХ ПРОВЕРОК
**СТРОГОЕ ПРАВИЛО РАЗРАБОТКИ ДЛЯ ВСЕХ АССИСТЕНТОВ И АГЕНТОВ DEEPSYQ**

## 1. СУТЬ ПРАВИЛА (SURGICAL PRECISION)
Когда владелец просит изменить один конкретный элемент (кнопку, ссылку, один стиль, одну строчку):
- **Идти строго в указанный файл и блок.**
- **Менять ТОЛЬКО то, о чём прямо попросили.**
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО:** 
  - Запускать аудит всего сайта или смежных разделов.
  - «Ходить и шастать» по другим файлам в поисках других неисправностей.
  - Перепроверять и переделывать страницы, о которых не просили.
  - Тратить время на бесконечные фоновые тесты там, где нужна точечная правка на 30 секунд.
- **Цикл выполнения:** Нашёл строку → Заменил → Закоммитил/Задеплоил → Кратко отчитался. Время выполнения: до 1–2 минут.

## 2. ПОЧЕМУ ЭТО КРИТИЧНО
Попытка «проверить всё подряд» парализует работу, приводит к задержкам на 30+ минут на банальную кнопку и ломает соседний рабочий код.

## 3. КАК ДАВАТЬ КОМАНДУ ДЛЯ МАКСИМАЛЬНОЙ СКОРОСТИ
Если нужно сделать молниеносно, владелец может сказать:
> *"Точечно: [кнопка/ссылка/элемент] — поменяй [А] на [Б] без лишних проверок."*

Агент обязан мгновенно выполнить только это точечное действие и немедленно остановиться.
