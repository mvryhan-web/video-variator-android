Inspired by successful media-first AI creative UX, **not by copying Lumina artwork, text, brand or page geometry**.

## Publication safety — mandatory, not optional
1. Generate each actual source image/video with a service whose **current terms permit its intended commercial website use**. Check that service's terms at creation time; don't assume rights merely because an AI generated it.
2. Capture a provenance record for **each real asset**, including: unique filename, original full prompt, source/provider and model, actual creation date, generation job/receipt ID (when provided), relevant commercial terms URL and access date, original file checksum (SHA-256), and any third-party inputs or licenses/consents.
3. No celebrity/recognizable private person, famous character, trademarked product, unlicensed music, real third-party photograph, logo, brand or protected artwork unless a separate documented right covers it. Prefer imaginary unbranded products and originally generated visual identities.
4. Check the **actual media file**: image and video play/resolve; actual ratios, duration, no artifacts, no watermarks or deceptive UI controls. For videos, verify real motion and quality; **a still image with a fake play button is not a video example**. Create the video with a genuinely supported video generator, not a static slideshow falsely presented as output.
5. Only after successful quality/rights review should the owner record `previewUrl`, optional `previewPosterUrl`, `rightsBasis` and a truthful specific `rightsNote` in **existing Owner AI Control**. Keep `active=false` and `featured=false` until explicitly approved.
6. Preview URLs need real accessible media. The current app does **not** provide an approved production object bucket for these assets; do not invent one or claim that uploading to GitHub is production storage.
7. Templates/Studio `defaultModel` and `defaultSettings` may only advertise currently connected, enabled and supported model capabilities. A creative brief's desired ratio or duration is **not** evidence of a working provider.
8. Never enable `AI_INSPIRATION_ENABLED`, live AI generation, production migrations, billing, provider spend or public website switch just to publish this pack.
