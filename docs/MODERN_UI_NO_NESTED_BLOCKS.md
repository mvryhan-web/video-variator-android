# ПРАВИЛО ВЛАДЕЛЬЦА: СОВРЕМЕННАЯ АРХИТЕКТУРА ИНТЕРФЕЙСА (NO NESTED BOXES)
**Дата утверждения:** 2026-11-09. Обязательно к неукоснительному исполнению во всех будущих задачах.

## 1. Запрет антипаттерна «блок в блоке» (Nested Cards / Containers):
- Категорически запрещено создавать тяжелые вложенные прямоугольные карточки с рамками и цветными фонами («коробка в коробке в коробке»).
- Никаких фиолетовых/серых массивных рамок, внутри которых лежат ещё рамки, а внутри них ещё кнопки-рамки.
- Макет должен быть чистым, плоским, пространственным и лёгким (Borderless Flat / Modern Glassmorphic Workspace), как на лучших продуктовых платформах мира (Apple, Stripe, Linear, Vercel, modern Figma).
- Разделение зон строится на логических разделах («в два раздела»), воздушных отступах (whitespace), чистой типографике и деликатных 1px разделителях (`rgba(255, 255, 255, 0.08)`), а не на громоздких контейнерах.

## 2. Мобильная вёрстка (Mobile First & Mobile Cleanliness):
- В мобильной версии недопустим «дурдом» из вертикальной стопки тяжелых коробок с отступами и рамками.
- Элементы должны перетекать в один гладкий эргономичный поток без визуального шума и двойных рамок.

## 3. Выпадающие и служебные меню:
- Никаких тяжелых плавающих модальных блоков с вложенными карточками для списков.
- Вместо блочных попапов использовать компактные раздвижные списки / лёгкие боковые шторки (Sliding Drawers) с плавной анимацией скольжения (`transform: translateX` / `translateY`).
- Кнопки действий («Новый диалог») оформляются как органичные аккуратные строки списка, а не отдельные массивные карточки-кнопки.
- Запрещено принудительно вставлять лишние блоки тарифов в меню навигации диалогов, когда пользователь ищет свои чаты.
