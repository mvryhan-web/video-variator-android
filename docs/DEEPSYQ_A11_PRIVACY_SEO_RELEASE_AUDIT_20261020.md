## 3. Safe staged SEO publication — release checklist, not execution authority

1. **Freeze identity and publication target:** D/owner resolve final branded canonical hostname, TLS, redirect policy between `/`, `/deepsyq.html`, legacy `index.html` and any future branded domain. Keep the isolated visual-preview service permanently noindex/Disallow and free of credentials; never conflate preview URL with public launch.
2. **Classify public vs private:** Keep workspace sessions, History, user results, uploads, credits, admin, consent and APIs non-indexable and authenticated. No private or user-generated content in sitemap, JSON-LD, OG, share cards, CDN or metadata. For public tools, make distinct crawlable static/SSR/prerender landing pages containing genuine HTML explanations and working examples; do not remove auth from Studio to appease crawlers.
3. **Metadata & internal links (C, PR323 coordination):** unique English title, description, H1, canonical, accessible text, truthful live feature descriptions; proper status for disabled models/trial. C requests narrow owner file hunk lease where PR323 touches HTML, rather than overlapping it. No invented UI, reviews or features. Mobile navigation and original Home untouched.
4. **Structured data only after validation (C):** `WebSite`/`Organization` on truly public pages and `SoftwareApplication` on working tools with verified URLs/publisher/capabilities. Validate JSON-LD syntax, visible-page match, legal brand identity; no `AggregateRating` or prices without real evidence. No fake `VideoObject` for still images/placeholder videos.
5. **Crawl controls & sitemap (D owns release, C checks):** remove currently noindex Home and AI Apps entries from active sitemap until their publication is explicitly approved. Include only indexable, unique, self-canonical 200 public URLs on chosen host; never include `product-video` or deleted destinations. Check robots directives, X-Robots-Tag, per-page robots, Googlebot/Bingbot/OAI-SearchBot and any intended AI crawlers for *public* pages; retain preview global denial, no private path leaks.
6. **Before opening indexing:** run zero-spend CI for XML parsing and sitemap⇔canonical⇔robots consistency, broken internal links, real 404 status, approved OG cards, responsive/mobile and Core Web Vitals. Verify robots/canonicals on actual deployed public host with `curl -I` and browser, not only GitHub source. D runs owner-authorized release checks; never enable paid generation/checkout just to satisfy SEO.
7. **Indexing only after owner/D launch authorization:** domain verification, submit public sitemap in Google Search Console and Bing Webmaster Tools, inspect URL Coverage/Page Indexing and Crawl Stats, compare actual search visibility (not `site:` alone). AI-search discoverability follows real crawlable helpful pages with accessible content; no guarantees of rankings or AI citations. Use legitimate EN/FR/RU `hreflang` and `x-default` only when complete live localized equivalents exist; do not index mixed-language half-translations.
8. **Measurement & rollback:** with compliant analytics consent, measure impressions, clicks, CTR, organic sign-ups, purchased-credit conversions and profit after provider cost; owner defines rollback to noindex for misleading/unready public landing pages. Preserve the preview noindex without exceptions.
