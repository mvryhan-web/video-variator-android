# Owner decision — freeze F8 virtual pets, 2026-11-03

**Status: FROZEN / not part of live DEEPSYQ or its DEV preview.**

The Luna dog, Mira cat, and Nova fox experiment is discontinued as an active feature pending a future explicit owner decision. Preserve all Blender sources, GLB models, PNGs, sprites, scripts, tests and historical commits in GitHub, including branch `archive-f8-pets-20261103`. Keep them out of the web runtime.

- Remove the 3D pet showcase from Home and disable the floating companion on public pages.
- Do not load `virtual-pet.js` or `virtual-pet.css` on site pages.
- Both `server/server.js` and `server/deepsyq-preview.js` return 404 for pet source/asset URLs before static serving and SPA fallback.
- Do not create additional Render services, volumes, databases, AI calls or work queues for pets.
- JARVIX is the only user-facing AI assistant and is unaffected by the freeze.
- Future PRs, deployments and agent assignments must **not** unfreeze F8 inadvertently.
- To resume F8, obtain fresh explicit owner authorization and show actual performance tests and useful functionality first.

This freeze does not cancel unrelated DEV or JARVIX development. Both live production and DEV preview must not serve public F8 code.
